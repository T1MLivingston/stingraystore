Monthly Points Upload

This page does not save anything and does not connect to GitHub on its own. It only turns a list of codes and points into the file format the store reads. This repository is public, so the access phrase above is a speed bump for casual visitors, not real security. The actual security is GitHub's own login, required to commit the file this page generates.

1. Paste this month's codes and points

One student per line: code, commendation points, conduct points. Comma or tab separated. Do not include names or student IDs.

2. Copy the generated file

3. Commit it to GitHub

Open the file in GitHub's editor, select all the existing text, paste in the copied file, then commit. You must be logged in to GitHub with write access to this repository.
